# 首次运行中的两个失败

## 1. 沙箱禁止本机HTTP连接

现象：服务日志显示监听成功，客户端访问127.0.0.1却收到Windows socket错误10013。

原因定位：独立健康检查请求也收到PermissionError。这是执行环境访问限制，不能仅因为服务日志出现listening就认定客户端可达。

处理：在获得授权的执行环境中运行；代码遇到权限错误时立即失败并保留状态，不再将它重复重试到启动超时。没有关闭操作系统安全功能。

## 2. llama-bench打不开中文绝对路径

现象：质量检查完成，测速进程退出1；stderr中模型路径出现乱码，报failed to open GGUF file。

修复：subprocess保持可执行文件绝对路径，设置cwd为模型父目录，向-m仅传英文模型文件名。相同模型文件不复制、不修改；哈希不变。

验证：增加自动检查，确认命令使用文件名、cwd为模型目录；随后实际运行相同Q8_0文件，GPU与CPU基准均完成。模型文件名本身仍建议使用ASCII，本修复没有解决任意非ASCII文件名的兼容性。
